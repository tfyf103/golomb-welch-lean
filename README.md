# Golomb–Welch conjecture in Lean

This repository hosts reproducibility materials for the Lean 4 formalization of Theorem 1.1 of *The Golomb–Welch conjecture for arbitrary centre sets* by Bocong Chen, Jing Huang, and Gaojun Luo.

The formalized theorem rules out tilings of the integer lattice by closed Lee balls for all dimensions \(n \ge 3\) and integer radii \(r \ge 2\), with arbitrary sets of centres. The entry point is `GolombWelch.main`, and the proof uses Lean 4.35.0.

Each release archive contains the proof sources, certificates, pinned dependencies, and reproduction instructions. The SHA-256 checksum is supplied alongside the archive.
